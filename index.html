WhatsApp Integration
Step-by-step setup guide
Step 01
Create a Meta Business Account
Go to business.facebook.com and create a free Meta Business account using your café's Facebook page or email. This is required to use the official WhatsApp Business API.
Step 02
Apply for WhatsApp Business API
Visit developers.facebook.com/docs/whatsapp → Click "Get Started" → Add a WhatsApp product to your app. You'll need a verified phone number (can be your existing +91 81599 92993) and business verification documents.
Step 03
Choose a BSP or Use Direct API
Option A — Easy (Recommended): Use a Business Solution Provider like Interakt, AiSensy, Wati, or Zoko. They give you a ready dashboard in ₹799–₹2,499/month, no coding needed.

Option B — Custom: Use Meta's Cloud API directly with a webhook. Requires a developer to write Node.js or Python code.
Step 04 · For Custom Dev
Set Up Your Webhook
When a customer places an order, this app can send a POST request to your backend, which then forwards it to WhatsApp using:

POST https://graph.facebook.com/v18.0/{phone-id}/messages

The message body includes order details — table number, items, and total. Your kitchen receives a WhatsApp message instantly.
Step 05
Create Message Templates
WhatsApp requires pre-approved templates for business-initiated messages. Create one like:

"🪷 New Order — Table {{1}}
{{2}}
Total: ₹{{3}}"

Submit for approval in Meta Business Manager. Usually approved within 24 hours.
Step 06
Connect This Menu App
Once API is ready, replace the placeOrder() function in this file to send a fetch() POST to your backend endpoint. Pass the order JSON. Your backend relays it to WhatsApp. Done — orders flow directly to your phone!
💡 Recommended for Bodhi Café
Use Interakt or AiSensy
For a small café, a no-code BSP is the fastest path. Sign up at interakt.ai or aisensy.com, connect your number, and use their API to receive formatted order messages. Setup takes 2–3 days including Meta verification.
